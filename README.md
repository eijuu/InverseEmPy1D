# InverseEmPy1D

1D inverse modeling for semi-airborne UAV-TEM data using empymod and PyQt6. Open source under Apache 2.0.

To use the program:
1. Download the project archive (*.zip)
2. Make sure you're using Python 3.14.0 (working with other versions is not guaranteed).
3. Create a virtual environment
4. Install the libraries listed in the "pyproject.toml" file (under [dependencies])
